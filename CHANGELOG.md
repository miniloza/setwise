# Setwise Changelog

## v1.3.0
- Switched the accent palette to Tiffany blue (`#81D8D0`) for the OLED look.
- Reworked the workout screen banner to match the new requested layout.
- Added Working set / Warm-up / Drop set options.
- Added half-rep tracking (`0–5`) for working and drop sets.
- Added 3-row drop-set entry.
- Renamed **End workout** to **End session**.
- Added adjustable rest timer in Settings.
- Added current bodyweight with dated history entries.
- Analytics now uses dated bodyweight entries where available.
- Moved exercise management out of the main bottom navigation and into Settings.
- Added session resume / reopen so a completed session can be continued later.
- Updated history so saved sessions can be edited more easily.
- Added body-part analytics overview plus exercise drill-down.
- Updated body-part cards on the overview to use muscle-figure graphics instead of text abbreviations.
