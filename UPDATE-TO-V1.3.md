# Update to Setwise v1.3.0

## Main changes
- Tiffany blue accent theme (`#81D8D0`)
- Body-part cards now use muscle-figure graphics instead of letter abbreviations
- Session screen updated to the new requested layout
- Working set / Warm-up / Drop set modes
- Half-rep tracking (0–5)
- 3-row drop-set logging
- Adjustable rest timer in Settings
- Current bodyweight saved with date history
- Analytics can use historical bodyweight relevant to the training date
- Exercise management moved into Settings
- Completed sessions can be reopened and continued later
- Session history supports easier set editing
- Body-part analytics overview plus exercise drill-down

## Install
Replace the hosted files with this package contents at the same app URL/path.
Keeping the same URL preserves the local IndexedDB workout data.
